# 灵契战歌 · Aethercall

一款原创的单机 CCG（集换式卡牌）对战端游，使用 Python + tkinter 实现，零第三方依赖，双击即玩。

## 快速开始

1. 确保已安装 Python 3.10 或更高版本（Windows 请使用 [python.org 官方安装包](https://www.python.org/downloads/)，安装时勾选 `Add python.exe to PATH`）。
2. 双击 `start.bat`。
3. 在主菜单选择自己的英雄与 AI 对手英雄，点击「开始对战」。

也可以手动启动：

```bat
python main.py
```

无界面的规则自检（AI 互相对战 36 局）：

```bat
python main.py --sim
```

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 点击手牌 | 打出卡牌；需要目标的卡牌会提示「请选择目标」 |
| 点击目标 | 为法术/战吼指定随从或英雄 |
| 点击自己的随从 → 点击敌方单位 | 发起攻击 |
| 点击英雄技能按钮 | 消耗 2 点法力使用英雄技能，每回合一次 |
| 结束回合按钮 / 空格键 | 结束当前回合 |
| ESC | 返回主菜单 |
| 点击空白区域 | 取消当前选择 |

界面右侧为法力水晶与实时对战日志，随从边框含义：金色描边为嘲讽，绿色描边表示本回合可攻击，黄色高亮为当前可选目标。

## 游戏规则

- 双方英雄初始 30 点生命，法力水晶每回合 +1，上限 10。
- 先手起手 3 张牌，后手 4 张牌；每回合开始抽 1 张牌。
- 牌库抽空后开始受到疲劳伤害，每次递增 1 点。
- 手牌上限 10 张，超出的牌会被烧掉；战场上限 7 个随从。
- 随从入场当回合无法攻击，除非拥有「冲锋」。
- 对方存在「嘲讽」随从时，必须先攻击嘲讽随从。
- 英雄生命降至 0 即败北；双方同时归零判定平局。

## 关键词能力

- **嘲讽**：敌方必须优先攻击它。
- **冲锋**：入场当回合即可攻击。
- **圣盾**：免疫下一次伤害。
- **冻结**：下个回合无法攻击。
- **光环**：为其他友方随从提供属性加成（如战阵督军、王庭勇士）。
- **战吼 / 亡语**：入场时或死亡时触发效果。

内置 4 个职业，每个职业含专属卡牌 + 中立卡牌构成的 30 张预组套牌，共 52 种卡牌：

| 英雄 | 职业 | 英雄技能 | 风格 |
| --- | --- | --- | --- |
| 塞拉菲娜·晨曜 | 法师 | 烈焰灼击：造成 1 点伤害 | 法术爆发、控场清场 |
| 格洛姆·裂颅 | 战士 | 披甲备战：获得 2 点护甲 | 护甲成长、处决换牌 |

## 项目结构

```
lushi/
├── start.bat          一键启动脚本（自动检测 Python 与 tkinter）
├── main.py            程序入口
├── README.md          本文档
└── aethercall/
    ├── cards.py       卡牌、英雄与预组套牌数据
    ├── engine.py      回合流程、伤害结算、效果解析、胜负判定
    ├── ai.py          启发式 AI 对手（斩杀检测、出牌评分、换血判断）
    ├── ui.py          tkinter 图形界面与交互
    └── simulate.py    无界面 AI 对战自检
```

## 扩展卡牌

在 `aethercall/cards.py` 中追加一条定义即可，效果由 `engine.py` 的 `apply_effect` 统一解析：

```python
_minion("my_card", "我的随从", 3, 3, 4, "战吼：抽一张牌。",
        keywords=("taunt",),
        effects=[{"type": "draw", "target": "owner", "amount": 1}])
```

可用的效果类型包括 `damage`、`aoe`、`heal`、`mass_heal`、`draw`、`armor`、`buff`、`grant`、`freeze`、`destroy`、`polymorph`、`random_damage`、`random_split`、`summon`、`summon_per_enemy`。

添加后把卡牌 ID 加入对应英雄的套牌列表，运行 `python main.py --sim` 验证规则未被破坏。

## 常见问题

- **双击 bat 闪退**：说明 Python 未加入 PATH，请重新安装 Python 并勾选该选项。
- **提示缺少 tkinter**：多见于精简版/商店版 Python，请改用官方安装包。
- **想调整 AI 强度**：修改 `aethercall/ai.py` 中的评分权重，或在 `aethercall/ui.py` 里调整 AI 行动间隔（`after` 的毫秒数）。
